LEARNING SUMMARY

What I Learned

For the first activity, I created a simple raster image using Canva, a website that offers many options for creating different types of images. For the second activity, I created a vector graphic using Adobe Illustrator, a program I usually use for creating different kinds of projects. In the third activity, I learned what Photoshop is and what it is used for. Since Photoshop is quite expensive, it is mainly recommended for professional use. However, I think it can also be useful for people who simply want to edit their photos in everyday life. It allows users to correct imperfections, adjust lighting and colors, and make images more visually attractive. It can also be used to make changes that look as realistic and natural as possible. For the fourth activity, I used the screen recording feature on my computer by pressing Windows + G to create a short video of about one minute to include on my web page. Finally, I uploaded the video to YouTube to get a direct link that I could use to embed it on my web page. I also added the image files I created to my web110 folder so they could be displayed correctly on the page. These activities helped me understand how different types of graphics and multimedia can be used to make a web page more interesting and visually appealing. I think this knowledge will be useful for creating and personalizing my own websites in the future.
