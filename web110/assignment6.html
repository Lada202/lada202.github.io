Assignment 6: Communications

Internet Collaboration Overview: Mailing List

This Mailing List activity explains that a mailing list sends emails to a group of subscribed people. The list server receives and distributes messages and automatically manages subscriptions. There are different types of mailing lists: response lists, compiled lists, announcement lists, and discussion lists. I learned that it is a useful service that makes sharing information easy. As a subscriber to a discussion list, I receive messages posted by other members, and when I post a message, the other subscribers receive it too. I found the information about subscribing to a mailing list very interesting. For some lists, you send an email to the administrative address with a subscription command and the list name in the body. You then receive a confirmation email with instructions, including how to unsubscribe. I think this is a useful service because, if I have my own business one day, I would add this option to keep my customers updated.

Screen Sharing / Remote Desktop: Chrome Remote Desktop

In the Chrome Remote Desktop activity, I learned that this tool allows users to see another computer’s screen and control it with a keyboard and mouse through a network. At first, this seems like an impossible feature, but after reading how it works, it seems quite possible. In simple terms, the tool sends mouse movements and keyboard commands to the remote computer, which sends back updates of its screen. A connection can be established after access has been authorized. I found this activity very interesting because it allows people to use a computer even when it is not in front of them. It also allows them to help another person or receive help when they have difficulty with a program or another computer issue. I will definitely use this tool in my personal and professional life. Being able to connect remotely could save me a lot of time and allow me to receive or provide help without being in the same place.

Intellectual Property: Research

In the Intellectual Property activity, after doing research on the internet, I learned from the NC State University website that illegally sharing copyrighted files through P2P applications or other methods can lead to serious consequences. These can include university disciplinary actions and civil or criminal penalties. I also learned that the university tries to prevent illegal file sharing, including by using technology that can monitor network traffic. Another thing I learned is that universities must provide information about legal alternatives to illegal downloading and share it with students and teachers. This article was interesting to read because it was informative. From now on, I will pay more attention to copyright when downloading or sharing files.
