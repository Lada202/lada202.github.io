ACTIVITY 02

Using Inline CSS

In the second activity, I learned that CSS basically allows us to change the layout of a web page, which can save a lot of work. There are three ways to use CSS: inline, internal, and external. Inline CSS uses the style attribute directly inside HTML elements, internal CSS uses a style element in the head section, and external CSS uses a link to connect an HTML page to a separate CSS file. The most common method is external CSS. In this activity, I practiced using inline CSS on one of my existing HTML pages, following a similar process to the first activity. I experimented with colors, font sizes, and text alignment. I noticed that inline and internal CSS can produce the same visual appearance, and the main difference is where the CSS code is written. The tutorial also explains colors, fonts, sizes, borders, padding, margins, and links, which are all useful things to know when creating web pages the way we like them. Each topic offers an exercise where we can test and learn. Finally, I used the W3C Validator to check for errors in my HTML code.

ACTIVITY 03

Practicing Internal CSS

For the third activity, I practiced using internal CSS, which was easier for me because I had already used it in my previous assignments. I usually write my CSS at the beginning of the HTML document and then continue with the content of the page. Finally, I used the W3C Validator for this activity as well to check for errors and correct them.

ACTIVITY 04

Creating External CSS

In my opinion, this is a more organized way to work because it keeps things separate from each other. In this exercise, I also played around with margins, fonts, and colors, and validated the CSS using the W3C CSS Validator.
