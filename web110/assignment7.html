Assignment 7: Introduction to Networking

Review Network Settings for Your System

In this activity, I checked the network settings on my computer using Microsoft’s guide. My Wi-Fi was connected, and airplane mode was off. I typed ipconfig in the Command Prompt and found my IP address, subnet mask, and default gateway. These names were new to me, but now I understand them better. The IP address identifies my computer on my local network, and the gateway allows it to reach other networks, including the Internet. I also found that my computer uses DHCP, so it receives its IP settings automatically.

I use the Internet every day to study, work on projects, do research, and talk with my family and friends, but I never paid much attention to how the connection works. This activity helped me understand it better. If I have connection problems in the future, I will know where to start checking.

Internet Reference Models

For the second activity, I learned about reference models, which explain how different devices communicate using common standards. I read about two models: OSI and TCP/IP. OSI is a model used to explain network communication. It has seven layers, and each layer has a specific job and provides services to the layer above it. TCP/IP is used on the Internet. It combines the physical and data link layers into one layer called host-to-network.

This activity helped me understand that everyday actions, like searching online or sending a document, are more complex than they seem. Behind these simple actions, data follows specific steps to reach its destination. This information helps me understand what happens when I use the Internet and do things online.

License and Support Costs

For the third activity, I compared the costs of Windows, macOS, and Linux using information from their official websites.

I learned that Windows 11 Home costs $139 if bought separately. Microsoft provides free online guides, but its premium support for one problem costs $49.

macOS is included when you buy a Mac, and system updates are free. Apple usually offers free technical support for the first 90 days.

For Linux, I looked at Ubuntu, which is free to use. Users can get free help from the community or pay for professional support.
