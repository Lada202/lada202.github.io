01 / WHAT I LEARNED

Introduction to SQL

In this activity, I learned that SQL is a language used to work with databases. It allows us to search for information, add new data, change existing information, or delete it. SQL can also be used to create databases and tables and control who can access certain information. Most of these actions are done using SQL statements with specific keywords. For example, SELECT * FROM Customers; shows all the customers in a table, along with information such as their names, addresses, and countries. I also learned that in many databases, a semicolon is used to separate SQL statements, allowing us to write more than one statement. I practiced using the SQL Tryit Editor on W3Schools, and I found it very useful because the tables already contain sample data. This makes it easier to try different commands and immediately see what happens without having to create a database from scratch. I think SQL is very useful for organizing and working with large amounts of information, especially when you need to find or update specific data.

02 / SQL COMMANDS

SQL Statements and Their Functions

The following statements demonstrate different SQL commands and explain what they can be used for.

Single-Table SELECT Statements

SQL Statement What It Does
  • SELECT * FROM Customers; SELECT * retrieves all columns and records from a table.
  • SELECT CustomerID, CustomerName FROM Customers; SELECT can retrieve specific columns instead of all the information.
  • SELECT CustomerName, Address, City, PostalCode FROM Customers WHERE Country = 'UK'; WHERE filters records using a specific condition.
  • SELECT ContactName, CustomerName FROM Customers ORDER BY ContactName ASC; ORDER BY sorts results. ASC means ascending order, such as A to Z.
  • SELECT COUNT(*) AS TotalCustomers FROM Customers; COUNT(*) counts the number of records. AS gives the result column a temporary name.
  • SELECT Country, COUNT(*) AS Total FROM Customers GROUP BY Country; GROUP BY organizes records that share the same value and allows counting each group.
  • SELECT Country, COUNT(*) AS Total FROM Customers GROUP BY Country ORDER BY Total DESC, Country ASC; ORDER BY can sort numerical results from highest to lowest using DESC, or alphabetically using ASC.
  • SELECT Country, COUNT(*) AS Total FROM Customers GROUP BY Country HAVING COUNT(*) > 10 ORDER BY Total DESC, Country ASC; HAVING filters grouped results based on a condition.

INSERT, UPDATE, and DELETE Statements

SQL Statement What It Does
  • INSERT INTO Shippers (ShipperID, ShipperName, Phone) VALUES (4, 'On Time Delivery', '(503) 555 0123'); INSERT INTO adds a new record to a table. VALUES specifies the information to add.
  • UPDATE Products SET Price = Price + 1; UPDATE modifies existing records. SET specifies the new value.
  • UPDATE Products SET Price = Price - 1; UPDATE can also decrease numerical values in existing records.
  • UPDATE Shippers SET ShipperName = 'On-Time Delivery' WHERE ShipperID = 4; UPDATE with WHERE changes only the records that meet a specific condition.
  • DELETE FROM Shippers WHERE ShipperID = 4; DELETE FROM removes records from a table. WHERE identifies which records to delete.
