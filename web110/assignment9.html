Exploring HTML, web hosting, and development tools.

01 / HTML BASICS

Introduction to HTML

In this activity, I learned that HTML is a markup language used to create and structure web pages. I learned that even a simple web page is made up of different elements, such as <!DOCTYPE html>, <html>, <head>, <title>, and <body>. These elements help organize the page and allow us to add text, images, videos, links, tables, and other content. Basically, HTML helps us structure everything properly so that the page looks organized and easy to navigate. Personally, I think learning how to build a web page from scratch is very useful because these skills could help me create my own website and promote my projects in the future.

02 / WEB HOSTING

Research Free Web Hosting Services

In this activity, I learned about free web hosting services and how they allow us to publish our websites online. I looked at three different services: GitHub Pages, Netlify, and Cloudflare Pages. They all offer free options for hosting websites, but I decided to try Netlify. Since I already had my previous assignments saved on GitHub, I connected my GitHub account to Netlify and selected the repository where I keep my HTML pages. After a few steps, my website was published, and I was able to open my Assignment 7 directly in the browser. I found this activity interesting because I discovered free websites that allow me to publish my work online.

03 / DEVELOPMENT TOOLS

Research Free HTML Editors

In this activity, I researched three free HTML editors: Visual Studio Code, Notepad++, and Bluefish. All three allow users to write and edit HTML code for creating web pages. Personally, I have already used Visual Studio Code during my previous semester to create a website for one of my projects. My experience with this tool was very positive. It is available in many different languages, allows users to automatically insert certain elements, and has a simple interface that is easy to understand. At first, it might seem a little confusing because there are so many options, but after using it for a while, you get used to it. I enjoyed working with Visual Studio Code so much that I decided to keep it installed on my computer for future use.
