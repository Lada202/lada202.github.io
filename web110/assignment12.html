06 / REFLECTION

What I Learned

In this activity, I learned that JavaScript is one of the three main languages used to create websites, along with HTML and CSS. While HTML is used to organize the content and CSS defines the appearance of a web page, JavaScript controls how the page behaves and makes it interactive. I found the example with the light bulb particularly interesting because it showed how JavaScript can change an image simply by clicking a button to turn the light on or off. Another interesting feature is that JavaScript can work with dates and times using Date objects and display them in different formats. Finally, I discovered that the HTML canvas element allows us to draw graphics, such as lines, circles, squares, and text, using JavaScript. Personally, I think these features are very useful because they allow us to create websites that are not only visually attractive but also interactive and functional. I could use this knowledge in the future to make my own web projects more interesting and engaging for visitors.
